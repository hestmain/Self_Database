柯西积分公式应用

#复变函数/例题 #复变函数/第4章

本篇演示 柯西积分公式 与 解析函数的导数公式 的标准用法。共同套路：确认围道方向与奇点位置 → 把被积函数写成 f(z)(z−z0)n+1 → 套公式。

柯西积分公式

例 1：奇点在围道内部

计算 ∮|z|=2ezz−1dz（正向）。

f(z)=ez 是整函数，z0=1 在 |z|=2 内部：

∮|z|=2ezz−1dz=2πif(1)=2πie

例 2：奇点在围道外部

计算 ∮|z|=1cos⁡zz−3dz（正向）。

奇点 z=3 在圆外，被积函数在 |z|≤1 上及其内部解析，由 柯西-古萨定理 直接得

∮|z|=1cos⁡zz−3dz=0

这就是"用公式前先看奇点位置"的意义。

例 3：分母是二次式

计算 ∮|z−2i|=1zz2+4dz（正向）。

z2+4=(z−2i)(z+2i)。在圆 |z−2i|=1 内部只有奇点 z0=2i（另一个奇点 −2i 到圆心距离为 4，在圆外）。取

f(z)=zz+2i,f(2i)=2i4i=12∮|z−2i|=1zz2+4dz=2πif(2i)=πi

例 4：围道内有多个奇点

计算 ∮|z|=2dzz2(z−1)（正向）。

圆内有两个奇点：z=0（二阶）与 z=1。把被积函数拆开：

1z2(z−1)=−1z−1z2+1z−1

逐项积分：∮|z|=2dzz=2πi，∮|z|=2dzz2=0，∮|z|=2dzz−1=2πi，于是

∮|z|=2dzz2(z−1)=−2πi−0+2πi=0

（1z2 的积分为零，也可用 解析函数的导数公式 理解：它对应 n=1、f(z)=1 的情形，f′(0)=0。）

若圆内有多个奇点，不能直接对整个被积函数套一次柯西积分公式（公式只允许分母出现一个 z−z0 因子）。做法是先部分分式拆项，或把围道拆成若干互不相交的小围道分别计算。

例 5：分子为常数，分母是二次式

设 C 是正向圆周 |z−i|=1，计算

∮Cdzz2+1

被积函数化为 1(z−i)(z+i)。取 f(z)=1z+i，它在 |z−i|≤1 上及其内部解析（奇点 −i 到圆心的距离为 2，在圆外），而 z0=i 在 C 内部，故

∮C1/(z+i)z−idz=2πif(i)=2πi⋅12i=π

留下的奇点 z=−i 在 C 外部，不需要处理。

例 6：三次分母，奇点在圆内

设 C 为正向圆周 |z|=2，计算 ∮Czdz(9−z2)(z+i)。

取 f(z)=z9−z2，它在 |z|≤2 上及其内部解析（奇点 ±3 在圆外），z0=−i 在圆内，故

∮Czdz(9−z2)(z+i)=2πif(−i)=2πi⋅−i9−(−1)=2πi⋅−i10=π5

例 7：高阶导数公式

计算 ∮|z|=1sin⁡zz4dz（正向）。

这里 f(z)=sin⁡z，z0=0，n=3，而 sin(3)⁡z=−cos⁡z，故 sin(3)⁡(0)=−1：

∮|z|=1sin⁡zz4dz=2πi3!⋅(−1)=−πi3
