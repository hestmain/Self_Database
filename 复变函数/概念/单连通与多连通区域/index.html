单连通与多连通区域

#复变函数/第4章

单连通区域

若区域 D 内任意一条简单闭曲线的内部都包含在 D 中，则称 D 是单连通区域，直观上就是"没有洞"。

若 D 不是单连通的，则称为多连通区域。若 D 内有 n 个洞，则称 D 是 n+1 连通的，n+1 称为它的连通度（连通阶数）。按这个记法单连通区域就是一连通的，环形域 r<|z|<R 有一个洞，是二连通区域。

定理

若 f 在单连通区域 D 内 解析，则对 D 内任意闭围道 C

∮Cf(z)dz=0

这是 柯西-古萨定理 的单连通版本（简单闭围道的结论可以推广到任意闭围道，因为闭围道可以拆成若干简单闭围道之和）。

多连通区域：挖洞公式

设 D 由外边界 C 与内边界 C1,C2,…,Cn 围成（D 有 n 个洞），f 在 D 及这些边界上解析。把 C 与每条 Ck 都取各自的正向（即各自逆时针），则 D 的正向边界是 C−C1−⋯−Cn：外边界逆时针走、每个洞的边界必须反向走，区域才始终位于行进方向左侧。对 D 用 柯西-古萨定理 得

∮Cf(z)dz−∑k=1n∮Ckf(z)dz=0

即

∮Cf(z)dz=∑k=1n∮Ckf(z)dz

直观说法：沿外边界绕一圈的积分，等于沿每个洞各绕一圈（同向）之和——中间相邻的反向部分互相抵消，只剩外边界和洞的边界。

方向与符号必须配套

上面的减号来自"内边界反向"。如果偷懒把内边界也取成顺时针直接相加，式子要改写成 ∮Cf+∑k∮Ckf=0，否则结论变成 ∮Cf=−∑k∮Ckf，符号全错。

检验：取 f(z)=1/z，D 为圆环 1<|z|<2，C 为 |z|=2、C1 为 |z|=1，两者都逆时针。由 围道积分 的幂函数积分，∮Cfdz=2πi、∮C1fdz=2πi，等式两边相等，符合。

围道变形原理

若闭围道 C1 能在 f 的解析区域内（不经过任何奇点）连续变形为 C2，则

∮C1fdz=∮C2fdz

教材称这条为道路变形原理（§46 推论），是上面挖洞公式的直接推论，也是实际计算时最常用的说法：把难算的围道"捏"成一个方便计算的圆周。
