积分模的上界

#复变函数/第4章

很多问题不需要算出积分，只需要知道它有多小。本节给出唯一但极强的工具。

基本估计式

若 f 在围道 C 上连续，则

|∫Cf(z)dz|≤∫C|f(z)||dz|

若进一步存在常数 M 使 |f(z)|≤M 在 C 上处处成立，而 L 是 C 的长度，则

|∫Cf(z)dz|≤ML

称此为 ML 估计。

推导

对分割和取模：

|∑kf(ζk)Δzk|≤∑k|f(ζk)||Δzk|≤M∑k|Δzk|

再用"折线长度不超过弧长"，令分割无限加细即得。本质上它就是 复变函数的定积分 中 |∫wdt|≤∫|w|dt 的围道版本。

两种典型用法

  1. 估个上界：把 |f| 在 C 上放大成常数 M，再用 M 乘以 C 的长度 L，得到 |∫Cfdz|≤ML。
  2. 证明某段积分趋于 0：让围道变大时 M 增长得比 L 慢。例如 CR 是半径 R 的上半圆弧，
|∫CRdzz2|≤1R2⋅πR=πR⟶0(R→∞)

这种"圆弧上的积分消失"的论证是后面留数计算和刘维尔定理的基础。
