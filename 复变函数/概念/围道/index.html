#复变函数/第4章

复变函数的积分是在"曲线"上做的，而不再是实轴上的区间。本节把"曲线"说得足够好，好到能对它积分。

曲线与参数表示

复平面上的一条曲线（弧）用实参数表示为

z(t)=x(t)+iy(t),a≤t≤b

其中 x(t),y(t) 是连续实函数，这样的曲线称为弧。

光滑弧与围道

  • 光滑弧：z′(t) 连续且处处不为零（曲线有连续转动的切线）
  • 围道：由有限条光滑弧首尾相接而成的曲线，即分段光滑弧
  • 围道的长度：
L=∫ab|z′(t)|dt
教材把"围道"作为积分路径的标准用词，后面所有 ∮Cf(z)dz 中的 C 都指围道。

简单曲线与简单闭曲线

  • 简单弧：z(t1)=z(t2) 仅在 t1=t2 时成立，即曲线不自交
  • 简单闭曲线：z(a)=z(b) 且除此之外不自交
  • Jordan 定理：一条简单闭曲线把复平面分成内部、外部和曲线本身三部分，其中内部是有界区域（见 点集相关基本概念）

方向

沿曲线前进时，若内部始终在左侧，则该方向称为正向（逆时针）；相反方向为负向（顺时针）。

  • 与 C 路径相同而方向相反的围道记为 −C，此时 ∫−Cfdz=−∫Cfdz
  • 同一条围道可以有无数种参数化，取定方向后积分值与具体参数化无关（见 围道积分）
看到记号 ∮C 时，第一件事是确认 C 的方向和它是否包围奇点。教材中"沿正向的简单闭围道"是最常见的设定。
