柯西积分公式

#复变函数/第4章

定理（柯西积分公式）

设 f 在一条沿正向的简单闭围道 C 上及其内部处处 解析，z0 是 C 内部的任意一点，则

f(z0)=12πi∮Cf(z)z−z0dz

写成便于计算积分的形式：

∮Cf(z)z−z0dz=2πif(z0)

意义

解析函数在区域内部的取值完全由它在边界上的取值决定。这是解析函数"刚性"的最直接表现：边界上的一小段信息就能锁死内部的全部取值（与 唯一确定的解析函数与反射原理 是同一主题）。

平均值性质

取 C 为以 z0 为心、ρ 为半径的正向圆周，代入 z=z0+ρeiθ、dz=iρeiθdθ，柯西积分公式给出

f(z0)=12πi∫02πf(z0+ρeiθ)ρeiθiρeiθdθ=12π∫02πf(z0+ρeiθ)dθ

即解析函数在圆心的值等于它在圆周上的平均值。这条性质在实数域没有对应者（实可微函数的中心值一般不等于平均值），也是 最大模原理 的直接来源：若 |f| 在圆心取到最大值，圆周上的平均值不可能更大，只能处处相等。

证明思路

  1. 以 z0 为心作足够小的正向圆周 Cρ（半径 ρ，完全位于 C 内部）。被积函数 f(z)z−z0 在 C 与 Cρ 之间的区域解析，由 单连通与多连通区域 的挖洞公式
∮Cf(z)z−z0dz=∮Cρf(z)z−z0dz
  1. 把 f(z) 拆成 f(z0)+[f(z)−f(z0)]，第一项
∮Cρf(z0)z−z0dz=f(z0)∮Cρdzz−z0=2πif(z0)
  1. 第二项由 f 在 z0 连续：对任意 ε>0，取 ρ 足够小使 |f(z)−f(z0)|≤ε 在 Cρ 上成立，由 积分模的上界
|∮Cρf(z)−f(z0)z−z0dz|≤ερ⋅2πρ=2πε→0
  1. 两式相加并令 ε→0 即得结论。
围道经过奇点时公式失效

例如计算 ∮|z−i|=1dzz2+1（见 柯西积分公式应用#柯西积分公式）时，若把围道换成 |z|=1，则 ±i 恰好落在围道上，被积函数在围道上无定义，柯西积分公式与高阶导数公式都不能直接用。选围道时要先检查奇点与围道的位置关系。

用公式前必须先判断 z0 与围道的位置关系。若被积函数的奇点全在 C 外部，则被积函数在 C 上及内部解析，由 柯西-古萨定理 积分直接为 0。围道内部有多个奇点时，要拆成多个"单奇点"积分分别算。

见 柯西积分公式应用#柯西积分公式。
