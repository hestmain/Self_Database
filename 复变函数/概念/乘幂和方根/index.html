乘幂和方根

#复变函数/第1章

复数乘幂

复数乘幂适合用指数形式计算。令 z=reiθ（r=|z|，θ 是 z 的某个辐角，见 复数的指数形式），则对一切整数 n=0,±1,±2,…

zn=rneinθ=rn(cos⁡nθ+isin⁡nθ)

为正整数时它就是 n 个相同因子相乘；n 为负整数时由 z−1=z―/|z|2 归纳得到。n=0 时 z0=1；n≤0 时整体要求 z≠0（00 无定义）。

当 r=1 时得到 de Moivre 公式（棣莫弗公式）

(cos⁡θ+isin⁡θ)n=cos⁡nθ+isin⁡nθ

复数方根

若 wn=z，则称 w 是 z 的 n 次方根，记作 w=zn。

设 z=reiθ≠0、w=ρeiφ，由 wn=z 得

ρn=r,nφ=θ+2kπ(k∈Z)

即

ρ=rn,φ=θ+2kπn=θn+2kπn

因此 w 的辐角取值集合是

Argw={θ+2kπn: k∈Z}

注意 θ 必须整个除以 n。取 k=0,1,…,n−1 就得到 n 个互不相同的值，继续增大 k 只是重复这些值，故

w=rnexp⁡(iθ+2kπn),k=0,1,…,n−1

这 n 个根落在以原点为心、rn 为半径的圆上，构成内接正 n 边形（相邻两根辐角相差 2π/n）。
