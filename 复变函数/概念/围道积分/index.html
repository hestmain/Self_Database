围道积分

#复变函数/第4章

定义

设围道 C 由 z(t)（a≤t≤b）给出，f 在 C 上分段连续，定义 f 沿 C 的积分为

∫Cf(z)dz=∫abf[z(t)]z′(t)dt

若 C 是闭围道，也记作 ∮Cf(z)dz。

这个定义把复积分化成了 复变函数的定积分，因此它的存在性、线性性都直接继承过来。

化为 实 线积分

由 f=u+iv 与 dz=dx+idy 展开：

∫Cf(z)dz=∫C(udx−vdy)+i∫C(vdx+udy)

这个形式是 柯西-古萨定理 中用 Green 公式证明的入口。

性质

  • 线性：∫C(αf+βg)dz=α∫Cfdz+β∫Cgdz
  • 反向变号：∫−Cfdz=−∫Cfdz
  • 路径可加：若 C 由 C1 的终点接 C2 的起点拼成，则 ∫C=∫C1+∫C2
  • 与参数化无关：同一方向下的不同参数化给出相同积分值
  • f 在 C 上连续时，积分的模有界（见 积分模的上界）

幂函数沿圆周的积分（核心例子）

设 C 是以 z0 为心、r 为半径的正向圆周，取 z=z0+reiθ，0≤θ≤2π。对整数 n：

∮C(z−z0)ndz={0,n≠−12πi,n=−1

即对所有整数 n，只有 n=−1 时积分不为零：n≥0 与 n≤−2 都给出 0（后者的被积函数在 C 上其实有界，但绕一圈后各段互相抵消，见下面的直接计算）。
n=−1 的计算：

∮Cdzz−z0=∫02πireiθreiθdθ=∫02πidθ=2πi

n≠−1 时 ∮C(z−z0)ndz=irn+1∫02πei(n+1)θdθ=0（n+1≠0）。

∮Cdzz−z0=2πi 是整个积分理论的"原子"。柯西积分公式 与 解析函数的导数公式 都是把它和别的函数乘起来再估计。
