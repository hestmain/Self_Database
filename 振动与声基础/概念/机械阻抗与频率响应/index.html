#振动与声基础/机械振动

机械阻抗与频率响应

机械阻抗把"力—振速"的关系写成与欧姆定律同形的复数量，使 m、D、Rm 三种元件可以直接相加，单自由度、双自由度乃至 N 自由度系统都用同一套网络语言处理。频率特性曲线（幅频、相频）就是 Zm 随频率的变化在位移、振速、加速度三种响应上的投影，判读共振、控制区与相位滞后都靠它们。

定义与量

机械阻抗：谐合激励下系统产生同频稳态振速，复数力 F~ 与复数振速 v~ 之比即该系统在该频率下的机械阻抗：

Zm=F~v~=Rm+jXreact,Xreact=mω−Dω,|Zm|=Rm2+(mω−Dω)2,φv=arctan⁡XreactRm
量 符号 SI 单位 说明
机械阻抗 Zm N·s/m（＝kg/s） 以速度为分母
阻（实部） Rm N·s/m 与力同相分量，对应耗散
抗（虚部） Xreact=mω−D/ω N·s/m 质量抗 mω 与弹性抗 −D/ω 之差
阻抗角 φv=arg⁡Zm rad 振速落后于力的相位
复力、复振速 F~, v~ N、m/s 复振幅（相量），模才是峰值，见 符号与约定

符号提醒：位移峰值 Xm（m）与电抗 Xreact（N·s/m）都带 X，但量纲不同、含义无关，答题时不要互换。

频率特性曲线：固定激励幅值与初相、改变频率，稳态同频响应的幅值—频率曲线称幅频特性曲线，相位—频率曲线称相频特性曲线。

核心公式

元件阻抗（同一振速、力相加，故阻抗直接相加）：

元件 力—速度关系 阻抗 数值示例（ω 上升时）
质量 m f=mv˙ jωm 随 ω 线性增大
弹簧 D（力顺 Cm=1/D） f=Dx=1Cm∫vdt Djω=−jDω=1jωCm 幅值随 ω 减小
阻尼 Rm f=Rmv Rm 与 ω 无关

稳态解与三种响应（激励 f(t)=F0cos⁡ωt，F0 为峰值）：

x~=F~jωZm,v~=F~Zm,a~=jωF~Zm
响应 幅值 相对激励的相位滞后
位移 Xm=F0ω|Zm| φx=φv+π2=arctan⁡mω−D/ωRm+π2
振速 Vm=F0|Zm| φv=arctan⁡mω−D/ωRm
加速度 am=ωF0|Zm| φa=φv−π2=arctan⁡mω−D/ωRm−π2

三个幅值满足 Vm=ωXm、am=ωVm=ω2Xm；三个相位相差 ±π/2，因为每求一次导（乘 jω）就超前 π/2。

量间联系：Zm 是"力除以速度"，故 Vm=F0/|Zm| 取极大的地方就是 |Zm| 取极小的地方（不是最大）。Rm 与频率无关，|Zm|2=Rm2+Xreact2 在 Xreact=0（即 ω=ω0）处取极小，故振速共振的判据就是 ω=ω0（见 共振谐振与输入功率）。

建模：从方程到阻抗

  1. 写方程 mx¨+Rmx˙+Dx=f(t)。
  2. 取 f(t)=F0ejωt、x~=x^ejωt，方程变为 (−mω2+jωRm+D)x^=F^。
  3. 两边除以 jω：[jωm+Rm+Djω]v^=F^，方括号即 Zm。
  4. 于是三种响应的幅相由 |Zm| 与 arg⁡Zm 一次给出，无需每次重解微分方程。

量纲检查：mω→kg⋅s−1；D/ω→(N/m)/(s−1)=N⋅s/m；Rm 本来就是 N⋅s/m。三者同量纲，才能相加。

频率特性的三段判读

记 ω0=D/m，则在 ω≪ω0、ω≈ω0、ω≫ω0 三个区段，响应由一个元件主导：

频段 |Zm| 主导项 位移幅值 位移相位 φx 物理含义
ω≪ω0 D/ω Xm≈F0/D，与频率无关 →0 刚度（弹性）控制，位移与力同相
ω=ω0 Xreact=0，|Zm|=Rm Xm=F0/(Rmω0) =π/2 位移落后力 90∘，速度与力同相
ω≫ω0 mω Xm≈F0/(mω2)∝ω−2 →π 质量控制，位移与力反相

振速与加速度的极限：

  • 振速：Vm≈F0ω/D (ω≪ω0) 随频率上升；在 ω=ω0 处 Vm=F0/Rm 取极大；Vm≈F0/(mω) (ω≫ω0) 随频率下降。φv 从 −π/2 经 0 变到 +π/2。
  • 加速度：am≈F0ω2/D（低频，随 ω2 上升）→ ω0 处 ω0F0/Rm → 高频趋于定值 F0/m。φa 从 −π（反相）经 −π/2 变到 0。

这三段结构就是判读实测频率特性曲线的依据：低频段是否水平、高频段是否按 ω−2 下降、共振峰高低与 δ 的关系，分别检验 D、m、Rm 是否估对。

适用条件与易错点

易错点

  1. 机械阻抗的分子分母：本笔记采用 Zm=F~/v~（以速度为分母）。有的资料用"力/位移"或"力/加速度"，数值和量纲都不同，换算前必须先看定义。
  2. Zm 不是声阻抗：机械阻抗（N·s/m）是集中参数系统的力与振速之比；声阻抗/比声阻抗（Pa·s/m）是声压与介质质点振速之比，两者只在特定条件下有对应关系，不可混用，见 基本声学量。
  3. 忽略弹性抗的负号：弹簧阻抗是 D/(jω)=−jD/ω，实部为零、虚部为负；把 mω−D/ω 写成 mω+D/ω 会导致共振频率算错。
  4. 输入阻抗与矩阵自阻抗不是一回事：单自由度只有一个元件串联的 Zm；双自由度里 Z11（F2 端短路时的输入阻抗）与自阻抗 Z1（F2 端开路）不同，见 两自由度耦合系统的受迫振动。
  5. 峰值与有效值：Zm 是复数振幅之比，用峰值或有效值算出的 Zm 相同（分子分母同乘 1/2），但功率公式里的 F02 若换成有效值就要去掉 1/2 因子。
  6. 相位参考量：φv 是振速相对力的滞后角，位移还要再加 π/2；答题须注明"相对谁"。

适用范围：线性、定常、单频稳态。瞬态段（暂态解未衰减完）不能用阻抗描述；非线性刚度或干摩擦不满足 Xreact=mω−D/ω 的形式。
