## 学习主线
1. 复数与复平面（第 1 章）→ 复变函数与解析性（第 2 章）
2. 初等函数（第 3 章）是解析函数的"样例库"
3. **积分（第 4 章）是分水岭**：[[复变函数/概念/柯西-古萨定理\|柯西-古萨定理]] 把"解析"翻译成"积分为零"，由此派生 [[复变函数/概念/柯西积分公式\|柯西积分公式]] → [[复变函数/概念/解析函数的导数公式\|解析函数的导数公式]] → [[复变函数/概念/最大模原理\|最大模原理]] 与 [[复变函数/概念/刘维尔定理与代数基本定理\|刘维尔定理与代数基本定理]]
4. 常见计算链：判断奇点位置 → 用围道变形把路径缩到奇点附近 → 套柯西积分公式/高阶导数公式
