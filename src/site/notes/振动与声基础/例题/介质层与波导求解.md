本篇演示 [[振动与声基础/概念/介质层的反射与透射\|介质层的反射与透射]] 与 [[振动与声基础/概念/平行平面层波导与频散\|平行平面层波导与频散]] 的标准算法。套路：**先定区域与正深度（层：$0<s<l$；波导：$0<x<h$）→ 写三区形式解与振速 → 折成输入阻抗或本征值 → 解系数 → 用能量关系、极限与极端情形检验**。材料参数取常见量级，结果保留三到四位有效数字，便于复核。

## 例 1：水–钢–水夹层的半波透明

**题**：水（$Z_1=Z_3=1.50\times10^6$ Pa·s/m）中夹一层厚 $l=29.5$ mm 的钢板（$\rho_2=7800$ kg/m³、$c_2=5900$ m/s，$Z_2=4.60\times10^7$ Pa·s/m）。求 $f=100$ kHz 与 $f=50$ kHz 时的声压反射系数、声压透射系数与透声系数。

**解**：

1. 夹层内波长与相位厚度：$\lambda_2=c_2/f$。
   - $f=100$ kHz：$\lambda_2=0.0590$ m，$\delta=2\pi l/\lambda_2=2\pi\times\dfrac{0.0295}{0.0590}=\pi$（整半波）；
   - $f=50$ kHz：$\lambda_2=0.118$ m，$\delta=\dfrac{\pi}{2}$（四分之一波）。
2. 阻抗比：$Z_2/Z_1=30.68$。
3. $f=100$ kHz（$\cos\delta=-1$，$\sin\delta=0$）：
$$R=\frac{Z_2(Z_3-Z_1)\cos\delta}{Z_2(Z_3+Z_1)\cos\delta}=0,\qquad
D_p=\frac{2Z_2Z_3}{Z_2(Z_1+Z_3)\cos\delta}=-1,\qquad T=1 .$$
4. $f=50$ kHz（$\cos\delta=0$，$\sin\delta=1$，且 $Z_1=Z_3$）：
$$R=\frac{j\left(Z_2^2-Z_1^2\right)}{j\left(Z_2^2+Z_1^2\right)}=\frac{941.3-1}{941.3+1}=0.99788,$$
$$D_p=\frac{2Z_2Z_3}{j\left(Z_2^2+Z_1^2\right)}=-j\frac{2Z_2Z_1}{Z_2^2+Z_1^2},\qquad
T=\frac{1}{\cos^2\delta+\frac14\left(\frac{Z_2}{Z_1}+\frac{Z_1}{Z_2}\right)^2\sin^2\delta}=\frac{1}{235.8}=4.24\times10^{-3}.$$

**检验**：

- $f=100$ kHz：$T=1$，$T\!L=0$ dB——半波透明：**板厚恰为夹层半波长的整数倍且 $Z_1=Z_3$** 时，钢板"声学透明"。
- $f=50$ kHz：$|R|^2=0.99576$，而 $T=1-|R|^2=4.24\times10^{-3}$（$Z_1=Z_3$ 时可直接用这一关系核对），对应 $T\!L=23.7$ dB。
- 频率只差一倍，透声从 $1$ 掉到 $4\times10^{-3}$：说明层的 $R$ 强烈依赖 $\delta=k_2l$（这里是单程相位，$100$ kHz 时 $\delta=\pi$，$50$ kHz 时 $\delta=\pi/2$），宽频信号穿层后一般会出现频率选择性失真——**透明只发生在离散频率上，不保证整个频带**。若带宽覆盖 $100$ kHz 附近，就需按带宽而非单频来设计夹层。
- $D_p=-1$（$f=100$ kHz）与 $T=1$ 并不矛盾：$T$ 用的是 $|D_p|^2$，符号来自 $\cos\delta<0$，属"相位翻转"而非能量损失。

## 例 2：四分之一波抗反射夹层

**题**：水（$Z_1=1.50\times10^6$）与钢（$Z_3=4.60\times10^7$）之间插入一层 $\rho_2=2000$ kg/m³ 的均匀材料作为抗反射层，工作频率 $f=100$ kHz。求匹配所需的 $c_2$、层厚 $l$，并计算 $R$、$D_p$、$T$；与不加夹层时对比。

**解**：

1. 四分之一波透明要求 $Z_2^2=Z_1Z_3$：
$$Z_2=\sqrt{1.50\times10^6\times4.60\times10^7}=8.31\times10^6\ \text{Pa·s/m}
\ \Longrightarrow\ c_2=\frac{Z_2}{\rho_2}=4150\ \text{m/s}.$$
2. 厚度取 $\delta=q_2l=\pi/2$：$\lambda_2=c_2/f=0.0415$ m，$l=\lambda_2/4=1.04\times10^{-2}$ m。
3. 输入阻抗：$Z_{\rm in}=Z_2^2/Z_3=1.500\times10^6\ \text{Pa·s/m}=Z_1$，故
$$R=\frac{Z_{\rm in}-Z_1}{Z_{\rm in}+Z_1}\approx0 .$$
4. 系数：
$$D_p=\frac{2Z_2Z_3}{j\left(Z_2^2+Z_1Z_3\right)}=-j\frac{Z_2}{Z_1},\qquad |D_p|=\frac{Z_2}{Z_1}=5.54=\sqrt{\frac{Z_3}{Z_1}} ,$$
$$T=\frac{Z_1}{Z_3}|D_p|^2=\frac{30.68}{30.68}=1 .$$
5. 不加夹层时（水/钢单界面）：$R=\dfrac{Z_3-Z_1}{Z_3+Z_1}=0.9369$，$T=1-|R|^2=0.1223$，$T\!L=9.1$ dB。

**检验**：

- $T=1$ 而 $|D_p|=5.54\ne1$：这正是"$T$ 与 $|D_p|$ 不能混"的例子。$|D_p|^2=Z_3/Z_1=30.7$ 也可由 $T=(Z_1/Z_3)|D_p|^2$ 反算得到（$30.68=30.68$）。
- 四分之一波条件与半波条件容易搞混：本例 $Z_1\ne Z_3$，**半波透明对它不成立**（把 $l$ 变成 $\lambda_2/2$ 时 $Z_{\rm in}=Z_3$，$R$ 反而回升到 $0.9369$）。
- 物理上这是"阻抗变换器"：$l=\lambda_2/4$ 把钢的阻抗"变"成 $Z_2^2/Z_3=Z_1$，让水看不到钢。缺点是**窄带**——离开 $f$ 一个倍频程，$R$ 就明显变大。
- 单界面与带层对比：$T$ 从 $0.122$ 提到 $1$，$T\!L$ 从 $9.1$ dB 降到 $0$ dB。

## 例 3：夹层消逝不等于全内反射

**题**：四组三层配置，入射角 $\theta_1=20^\circ$（其中 (b) 另取 $45^\circ$），判断各属哪种波场类型（A 全正常 / B 夹层消逝但外侧透射 / C 全内反射而夹层正常 / D 全内反射且夹层消逝），并说明判据。

| 组 | $c_1$ | $c_2$（夹层） | $c_3$（外侧） |
|---|---|---|---|
| (a) | 1500 | 1200 | 1700 |
| (b) | 1500 | 3000 | 1700 |
| (c) | 1500 | 1200 | 5900 |
| (d) | 1500 | 5900 | 5900 |

**解**：两个判据**互相独立**：

- **外层**决定有无全内反射：需 $c_1<c_3$ 且 $\theta_1\ge\theta_{c13}=\arcsin(c_1/c_3)$；
- **夹层**决定它自己是否消逝：需 $c_2>c_1$ 且 $\theta_1>\theta_{c12}=\arcsin(c_1/c_2)$。

逐组算：

- (a) $\theta_{c13}=\arcsin(1500/1700)=62.0^\circ>20^\circ$（无全内反射）；$c_2<c_1$，夹层永不消逝 → **类型 A**。
- (b) 外层同上无全内反射；夹层 $\theta_{c12}=\arcsin(1500/3000)=30.0^\circ$。$\theta_1=20^\circ<30^\circ$ → 夹层传播，**类型 A**；$\theta_1=45^\circ>30^\circ$ → 夹层消逝而外侧仍透射，**类型 B**。
- (c) $\theta_{c13}=\arcsin(1500/5900)=14.7^\circ<20^\circ$ → 全内反射；$c_2<c_1$，夹层始终正常传播 → **类型 C**。
- (d) $\theta_{c13}=14.7^\circ<20^\circ$ → 全内反射；夹层 $\theta_{c12}=\arcsin(1500/5900)=14.7^\circ<20^\circ$ → 夹层消逝 → **类型 D**。

夹层消逝时的衰减常数（(b) 的 $45^\circ$ 情形，取 $f=1$ kHz，夹层密度取 $\rho_2=1000$ kg/m³；$\rho$ 只进入 $Z_{2n}$，不影响类型判定）：$k_1=4.189$ rad/m、$k_2=2.094$ rad/m，$\omega=2\pi f=6283$ rad/s，

$$\alpha_2=\sqrt{k_1^2\sin^2\theta_1-k_2^2}=\sqrt{17.55\times0.5-4.386}=2.09\ \text{m}^{-1},\qquad \frac1{\alpha_2}=0.478\ \text{m},$$

$$Z_{2n}=\frac{\rho_2\omega}{-j\alpha_2}=j\frac{\rho_2\omega}{\alpha_2}=j\,3.0\times10^6\ \text{Pa·s/m}\quad(\text{纯虚}).$$

**检验**：

- (b) 中 "$30^\circ<\theta_1$" 与 (c)(d) 中 "$14.7^\circ<\theta_1$" 是**两个不同角**：前者是介质 1 与夹层的临界角，后者是介质 1 与介质 3 的临界角。把二者混为一谈，就会误判"夹层消逝 ⇒ 全内反射"。**反例就是 (b) 的 $45^\circ$：夹层已消逝，能量照样透出去。**
- (d) 的两个临界角恰好相等，因为 $c_2=c_3$；此时两种现象同时出现，最容易看不出因果，建议用 (b) 来理解"独立性"。
- $\alpha_2=k_2$ 是 $c_2=2c_1$、$\theta_1=45^\circ$ 的巧合（$k_1^2/2-k_2^2=k_2^2$），可用来核对代数；$|Z_{2n}|=Z_2$ 也可作为自检（$Z_{2n}=j\rho_2\omega/\alpha_2$，当 $\alpha_2=k_2$ 时模恰为 $\rho_2c_2$）。$Z_{2n}$ 的数值可复算：$\rho_2\omega/\alpha_2=1000\times6283/2.09=3.0\times10^6$ Pa·s/m。
- 夹层消逝时夹层内必须保留 $B_2e^{+\alpha_2s}$（增长项）：有限厚层里"靠界面一侧衰减、靠出口一侧增长"两个波都要，删掉任一项都会让 $s=l$ 处的边条件无法满足。

## 例 4：硬壁波导的模式计数与相速度群速度

**题**：水（$c=1500$ m/s）充满 $h=0.10$ m 宽的两块绝对硬平行板之间。求各阶截止频率、$f=20$ kHz 与 $f=10$ kHz 时传播的模数、$f=20$ kHz 时各传播模的相速度与群速度，以及单模工作的频率上限。

**解**：

1. 截止频率：$f_n=\dfrac{nc}{2h}=\dfrac{1500n}{0.20}=7500n$ Hz。故 $f_1=7.5$ kHz、$f_2=15$ kHz、$f_3=22.5$ kHz。
2. 传播条件 $f>f_n$：
   - $f=20$ kHz：$n=0,1,2$ 传播（$n=3$ 需 $22.5$ kHz）→ **3 个模**；
   - $f=10$ kHz：$n=0,1$ → **2 个模**。
3. $f=20$ kHz 时 $k=\omega/c=83.78$ rad/m，$n\pi/h=31.42n$ rad/m：

| $n$ | $k_{xn}$ (1/m) | $k_{zn}=\sqrt{k^2-k_{xn}^2}$ (1/m) | $c_{pn}=\omega/k_{zn}$ (m/s) | $c_{gn}=c^2/c_{pn}$ (m/s) |
|---|---|---|---|---|
| 0 | 0 | 83.78 | 1500 | 1500 |
| 1 | 31.42 | 77.66 | 1618 | 1391 |
| 2 | 62.83 | 55.41 | 2268 | 992 |

4. 单模上限：只有 $n=0$ 传播需 $f<f_1=7.5$ kHz，等价于 $h<\dfrac{c}{2f}$。

**检验**：

- 用 $c_{gn}=c\sqrt{1-(f_n/f)^2}$ 独立复算 $n=1$：$1500\sqrt{1-(7.5/20)^2}=1391$ m/s ✓；$c_{p1}c_{g1}=1618\times1391=2.25\times10^6=c^2$ ✓。
- 零阶模：$k_{x0}=0$、$c_{p0}=c_{g0}=c$，就是自由场平面波，"无截止"与"零阶模恒传播"一致。
- 阶数越高 $c_p$ 越大、$c_g$ 越小；$n=2$ 已接近截止（$f_2=15$ kHz 对 $f=20$ kHz），故 $c_{p2}$ 明显大于 $c_{p1}$。
- 边界上的必需检查：把 $f$ 调到恰为 $7.5$ kHz 时 $k_{z1}=0$，$c_{p1}$ 发散——**等号不算传播**。此时该阶的轴向解允许一个线性项 $c_0+c_1z$，靠"$z\to+\infty$ 有界"才压成横截面上的驻波图案；同时该阶的 $u_z\propto k_{z1}$ 恒为零，无法与给定的源振速匹配，幅值公式分母为零、不能用来求稳态幅值。这正是必须把截止点单独讨论的原因。

## 例 5：均匀源与余弦源激励的简正波幅值

**题**：上例波导（$h=0.10$ m、$c=1500$ m/s、$\rho=1000$ kg/m³），$f=20$ kHz。$z=0$ 处的源分别为 (i) 均匀振速 $v(x)=v_0=0.010$ m/s；(ii) $v(x)=v_0\cos(\pi x/h)$。求各阶幅值 $A_n$ 与声压场，并给出轴向波长。

**解**：用

$$A_n=\frac{\rho\omega}{k_{zn}N_n}\int_0^hv(x)\cos\frac{n\pi x}{h}\,\mathrm dx,\qquad N_0=h,\ N_n=\frac h2\ (n\ge1),$$

其中 $\omega=1.2566\times10^5$ rad/s，$k_{z0}=83.78$、$k_{z1}=77.66$、$k_{z2}=55.41$ 1/m（例 4）；$v(x)$ 与 $A_n$ 均按复振幅处理，题给实数幅值即取零初相。

**(i) 均匀源**：$n\ge1$ 时 $\int_0^hv_0\cos(n\pi x/h)\mathrm dx=0$，只有

$$A_0=\frac{\rho\omega}{k_{z0}h}\,v_0h=\rho cv_0=1000\times1500\times0.010=1.5\times10^4\ \text{Pa},$$

$$p=\rho cv_0e^{j(\omega t-kz)}=1.5\times10^4e^{j(\omega t-83.78z)}\ \text{Pa},$$

这是含 $e^{j\omega t}$ 的**复数场表达式**（$p$ 为复声压），物理声压取实部：$p_{\rm phys}=\operatorname{Re}\{p\}=1.5\times10^4\cos(\omega t-83.78z)$ Pa。

**(ii) 余弦源**：$n=0$ 时 $\int_0^hv_0\cos(\pi x/h)\mathrm dx=\dfrac{v_0h}{\pi}\left[\sin\dfrac{\pi x}{h}\right]_0^h=0$；$n=1$ 时 $\int_0^hv_0\cos^2\dfrac{\pi x}{h}\mathrm dx=\dfrac{v_0h}{2}$，故

$$A_1=\frac{\rho\omega}{k_{z1}(h/2)}\cdot\frac{v_0h}{2}=\frac{\rho\omega v_0}{k_{z1}}
=\frac{1000\times1.2566\times10^5\times0.010}{77.66}=1.62\times10^4\ \text{Pa},$$

$$p=A_1\cos\frac{\pi x}{h}e^{j(\omega t-k_{z1}z)},\qquad A_n=0\ (n\ne1),$$

同样地，$p$ 是复声压，物理声压取实部；$A_1$ 在此取实数即表示源面上零初相。

**检验**：

- (i) 的 $A_0=\rho cv_0$ 与"波阻抗 $p/u=\rho c$"一致：$u_z=\dfrac{k_{z0}}{\omega\rho}A_0=\dfrac{83.78\times1.5\times10^4}{1.2566\times10^5\times1000}=0.010$ m/s ✓，且 $p$ 与 $x$ 无关，自动满足两壁 $\partial p/\partial x=0$。
- (ii) 的源与本征函数 $\cos(\pi x/h)$ 成正比，只有对应阶被激励；$A_0=0$ 可由 $\int_0^h\cos(\pi x/h)\mathrm dx=[\sin(\pi x/h)]_0^h/(\pi/h)=0$ 直接看出。
- 轴向波长：$n=1$ 在 $f=20$ kHz 时 $\lambda_{z1}=2\pi/k_{z1}=0.0809$ m，大于自由场波长 $\lambda=c/f=0.0750$ m——波导内"沿轴看"的波长被拉长，与 $c_{p1}>c$ 是同一件事。
- 归一化自检：若改用 $\varepsilon_0=2$、$\varepsilon_{n\ne0}=1$，$A_n$ 的表达式应写成 $A_n=\dfrac{2\rho\omega a_n}{h\varepsilon_nk_{zn}}$（$a_n=\int_0^hv\cos(n\pi x/h)\mathrm dx$）；(i)(ii) 两种算法结果相同，说明两套归一化没有矛盾，**只要篇内不混用**。
- 频率下调到 $5$ kHz 时 $f_1=7.5$ kHz $>5$ kHz，(ii) 的 $\cos(\pi x/h)$ 源将不再激发传播模（$k_{z1}$ 变纯虚），场退化为源附近的倏逝模。
