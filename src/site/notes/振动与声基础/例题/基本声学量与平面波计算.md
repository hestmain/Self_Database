本篇演示 [[振动与声基础/概念/基本声学量\|基本声学量]]、[[振动与声基础/概念/声能密度声强与声级\|声能密度声强与声级]]、[[振动与声基础/概念/平面行波\|平面行波]]、[[振动与声基础/概念/声学基本方程与速度势\|声学基本方程与速度势]] 的标准算法。共同套路：**先定介质与时间因子 → 分清峰值/有效值 → 用 $p\leftrightarrow u\leftrightarrow\rho'\leftrightarrow s$ 的换算链 → 用能量关系与行波关系互相核对**。

介质参数取常见量级：空气 $\rho_0=1.2$ kg/m³、$c=345$ m/s（$Z_c=414$ Pa·s/m）；水 $\rho_0=1000$ kg/m³、$c=1500$ m/s（$Z_c=1.5\times10^6$ Pa·s/m）。所有题的时间因子为 $e^{j\omega t}$，带下标的幅值默认是**峰值**。

## 例 1：声压、振速、密度逾量与压缩量的换算

**题**：空气中一列 $f=1.0$ kHz 的单频平面行波，声压**峰值** $\hat p_0=2.0$ Pa。求声压有效值、声压级、质点振速的峰值与有效值、密度逾量、压缩量、声强、声强级与质点位移幅值；并核对"压缩量 = 振速/声速"。

**解**：

1. 特性阻抗 $Z_c=\rho_0c=1.2\times345=414$ Pa·s/m。
2. 有效值 $p_{\rm rms}=p_0/\sqrt2=2.0/1.41421=1.414$ Pa。
3. 声压级
$$\mathrm{SPL}=20\lg\frac{1.414}{20\times10^{-6}}=20\lg(7.071\times10^4)=96.99\ \text{dB}\approx97.0\ \text{dB}.$$
4. 振速（单向行波 $u=p/Z_c$，同相）
$$u_0=\frac{p_0}{Z_c}=\frac{2.0}{414}=4.831\times10^{-3}\ \text{m/s},\qquad
u_{\rm rms}=\frac{4.831\times10^{-3}}{\sqrt2}=3.416\times10^{-3}\ \text{m/s}.$$
5. 密度逾量与压缩量（状态方程 $p=c^2\rho'$）
$$\rho'=\frac{p_0}{c^2}=\frac{2.0}{345^2}=\frac{2.0}{1.19025\times10^5}=1.680\times10^{-5}\ \text{kg/m}^3,$$
$$s=\frac{\rho'}{\rho_0}=\frac{1.680\times10^{-5}}{1.2}=1.400\times10^{-5}.$$
6. 声强（峰值口径）
$$I=\frac{p_0^2}{2Z_c}=\frac{4.0}{2\times414}=4.831\times10^{-3}\ \text{W/m}^2 .$$
7. 声强级
$$\mathrm{SIL}=10\lg\frac{4.831\times10^{-3}}{10^{-12}}=10\lg(4.831\times10^{9})=96.84\ \text{dB}.$$
8. 位移幅值
$$\omega=2\pi f=6.2832\times10^{3}\ \text{rad/s},\qquad
\xi_0=\frac{u_0}{\omega}=\frac{4.831\times10^{-3}}{6.2832\times10^3}=7.69\times10^{-7}\ \text{m}\approx0.77\ \mu\text{m}.$$

**检验**：

- **两条独立路径算 $s$**：$s=p_0/(\rho_0c^2)=2.0/(1.2\times1.19025\times10^5)=1.400\times10^{-5}$ ✓；$s=u_0/c=4.831\times10^{-3}/345=1.400\times10^{-5}$ ✓。两式一致说明振速与压缩量的关系没写错（差一个 $c$ 是最常见的错）。
- $s$ 与 $k\xi_0$ 一致：$k=\omega/c=18.21$ rad/m，$k\xi_0=18.21\times7.69\times10^{-7}=1.40\times10^{-5}$ ✓（$s=-\nabla\cdot\boldsymbol\xi$ 的一维形态）。
- **SPL 与 SIL 差 0.15 dB 不是算错**：两者只在 $I_{\rm ref}=p_{\rm ref}^2/(\rho_0c)$ 严格成立时才相等。空气实际 $\rho_0c=414$ 而参考体系隐含 $400$（$20\ \mu$Pa 对应 $10^{-12}$ W/m² 用的是 $\rho_0c=400$），故 $\mathrm{SIL}=\mathrm{SPL}+10\lg(400/414)=\mathrm{SPL}-0.15$ dB ✓。
- $s\ll1$ 与 $u_0\ll c$ 都成立（$10^{-5}$ 量级），线性声学与小振幅假设自洽。
- **量级自检**：$1$ kHz 时空气质点振幅不到 $1\ \mu$m，声压 97 dB 对应的振幅却如此之小——这是"声压大"与"位移大"不构成正比的直接例子。

## 例 2：平面行波的能量、声强与能流

**题**：水中一列 $f=5.0$ kHz 的单频平面行波，声强 $I=1.0\times10^{-3}$ W/m²。求：(a) 声压的有效值与峰值、振速的峰值、波长与波数；(b) 平均与峰值声能密度、瞬时声能流密度的表达式及其峰值；(c) 声强级；(d) 同样的声强在空气中对应多大的声压与振速，并解释差异。

**解**：

1. $Z_c=\rho_0c=1000\times1500=1.5\times10^6$ Pa·s/m。
2. 声压
$$p_{\rm rms}=\sqrt{IZ_c}=\sqrt{10^{-3}\times1.5\times10^{6}}=\sqrt{1500}=38.73\ \text{Pa},\qquad
p_0=\sqrt2\times38.73=54.77\ \text{Pa}.$$
3. 振速
$$u_0=\frac{p_0}{Z_c}=\frac{54.77}{1.5\times10^6}=3.651\times10^{-5}\ \text{m/s}.$$
4. 波长与波数
$$\lambda=\frac{c}{f}=\frac{1500}{5000}=0.30\ \text{m},\qquad k=\frac{2\pi}{\lambda}=20.94\ \text{rad/m}.$$
5. 声能密度（平均与峰值）。平面行波的平均声能密度即 $I/c$：
$$\overline{E_0}=\frac{I}{c}=\frac{1.0\times10^{-3}}{1500}=6.667\times10^{-7}\ \text{J/m}^3 .$$
峰值是平均的 2 倍（$\cos^2$ 因子）：
$$E_{0,\max}=\rho_0u_0^2=1000\times\left(3.651\times10^{-5}\right)^2=1.333\times10^{-6}\ \text{J/m}^3 .$$
6. 瞬时声能流密度。由 $p=p_0\cos(\omega t-kx)$、$u=(p_0/Z_c)\cos(\omega t-kx)$：
$$W=pu=\frac{p_0^2}{Z_c}\cos^2(\omega t-kx)=I\left[1+\cos2(\omega t-kx)\right],\qquad W_{\max}=2I=2.0\times10^{-3}\ \text{W/m}^2 .$$
7. 声强级
$$\mathrm{SIL}=10\lg\frac{10^{-3}}{6.7\times10^{-19}}=10\lg(1.493\times10^{15})=151.7\ \text{dB}.$$
8. 空气中的同一强度（$Z_{c,\text{air}}=414$ Pa·s/m）
$$p_{\rm rms}=\sqrt{10^{-3}\times414}=\sqrt{0.414}=0.643\ \text{Pa},\qquad
u_{\rm rms}=\sqrt{\frac{I}{Z_{c,\text{air}}}}=\sqrt{\frac{10^{-3}}{414}}=1.554\times10^{-3}\ \text{m/s},$$
$$\mathrm{SPL}=20\lg\frac{0.643}{20\times10^{-6}}=90.2\ \text{dB}.$$

**检验**：

- **能量守恒链**：平均声能密度 × 声速应与声强相等：$6.667\times10^{-7}\times1500=1.0\times10^{-3}$ ✓。
- **两式算能流峰值一致**：$2I=2.0\times10^{-3}$ 与 $p_0^2/Z_c=54.77^2/1.5\times10^6=2.0\times10^{-3}$ ✓。
- **介质对比的解析预期**：同一 $I$ 下 $p\propto\sqrt{Z_c}$，比值为 $\sqrt{1.5\times10^6/414}=\sqrt{3623}=60.2$；实际 $38.73/0.643=60.2$ ✓。振速比恰为倒数：$1.554\times10^{-3}/2.582\times10^{-5}=60.2$ ✓。这正是 [[振动与声基础/概念/平面行波\|平面行波]] 的"同声强下阻抗大的介质声压大、振速小"。
- **$W$ 恒非负**：$I[1+\cos2(\cdot)]\ge0$。单向行波中 $p$、$u$ 同相，任何时刻都没有反向能流；若写成 $p-u$ 有相位差（驻波、近场），$W$ 就会在部分时刻为负。
- **级的陷阱**：水中 151.7 dB、空气中 90.2 dB 却是**同一个声强**。两个数值差 $61.6$ dB $=$ $20\lg20=26.0$ dB（参考声压不同）$+$ $10\lg(1.5\times10^6/414)=35.6$ dB（阻抗不同）。跨介质比"级"的数字是无效的。

## 例 3：由边界振速求平面行波场与速度势

**题**：水（$\rho_0=1000$ kg/m³、$c=1500$ m/s）占半无限空间 $x>0$。$x=0$ 处的活塞作简谐振动，法向振速 $u(0,t)=u_0\cos\omega t$，$u_0=1.0\times10^{-4}$ m/s，$f=1.0$ kHz。求：(a) 声压场 $p(x,t)$ 与振速场 $u(x,t)$；(b) 速度势 $\hat\Psi(x)$，并验证 $\mathbf u=-\nabla\Psi$；(c) 声强与平均声能密度；(d) $x=\lambda/4$ 处的声压与振速。

**解**：

1. 参数：$Z_c=1.5\times10^6$ Pa·s/m，$\omega=6.2832\times10^3$ rad/s，$k=\omega/c=4.1888$ rad/m，$\lambda=c/f=1.5$ m。
2. 介质在 $x>0$ 内无源、且 $x\to+\infty$ 方向没有远处来的入射波（无回波），故只有正向行波，$u(x,t)=u_0\cos(\omega t-kx)$ 可直接写出（波形由边界给定，传播中不变）。由行波关系
$$p_0=Z_cu_0=1.5\times10^6\times1.0\times10^{-4}=150\ \text{Pa},$$
$$\boxed{p(x,t)=150\cos\left(6.2832\times10^{3}t-4.1888x\right)\ \text{Pa}},\qquad
u(x,t)=1.0\times10^{-4}\cos\left(6.2832\times10^{3}t-4.1888x\right)\ \text{m/s}.$$
3. **速度势**。由 $\hat p=j\omega\rho_0\hat\Psi$：
$$\hat\Psi=\frac{\hat p}{j\omega\rho_0}=\frac{150e^{-jkx}}{j\times6.2832\times10^3\times10^3}=-j\,2.387\times10^{-5}e^{-jkx}\ \text{m}^2/\text{s}.$$
4. **反向核对**：$\hat u=-\dfrac{\partial\hat\Psi}{\partial x}$，
$$\frac{\partial\hat\Psi}{\partial x}=(-j\,2.387\times10^{-5})(-jk)e^{-jkx}=(-k\times2.387\times10^{-5})e^{-jkx}=-1.000\times10^{-4}e^{-jkx},$$
$$\hat u=+1.000\times10^{-4}e^{-jkx}\ \checkmark$$
5. 声强与平均声能密度
$$I=\frac{p_0^2}{2Z_c}=\frac{150^2}{2\times1.5\times10^6}=7.5\times10^{-3}\ \text{W/m}^2,\qquad
\overline{E_0}=\frac{I}{c}=5.0\times10^{-6}\ \text{J/m}^3 .$$
6. $x=\lambda/4=0.375$ m 处：$kx=\dfrac{2\pi}{\lambda}\cdot\dfrac{\lambda}{4}=\dfrac{\pi}{2}$，故
$$p=150\cos\left(\omega t-\frac{\pi}{2}\right)=150\sin\omega t,\qquad
u=1.0\times10^{-4}\sin\omega t .$$

**检验**：

- **用振速口径重算声强**：$I=\frac12Z_cu_0^2=0.5\times1.5\times10^6\times(10^{-4})^2=7.5\times10^{-3}$ ✓，与 $p_0^2/(2Z_c)$ 一致。两式相等当且仅当 $p_0=Z_cu_0$，所以这一步同时验证了行波关系与特性阻抗没写错。
- **用有效值口径复核**：$p_{\rm rms}=150/\sqrt2=106.07$ Pa，$I=p_{\rm rms}^2/Z_c=11250/1.5\times10^6=7.5\times10^{-3}$ ✓。峰值公式与 rms 公式的 $1/2$ 只出现一次。
- **能量密度自检**：$\frac12\rho_0u_0^2=0.5\times1000\times10^{-8}=5.0\times10^{-6}=\overline{E_0}$ ✓（平面行波动能与势能平均各占一半）。
- **速度势的量纲**：$[\Psi]=$ m²/s，与 $\mathbf u=-\nabla\Psi$ 一致；若算出 m²/s² 说明把 $p=\rho_0\partial\Psi/\partial t$ 漏了 $\rho_0$。
- **$\lambda/4$ 处的相位**：$kx=\pi/2$ 只是"传播带来的相位落后"，$p$ 与 $u$ **仍然同相**（都成为 $\sin\omega t$）。单向行波场中 $p$、$u$ 始终同相，位置只改变两者的共同相位——这一点常被误以为"$\lambda/4$ 处反相"（那是驻波的性质，见 [[振动与声基础/概念/驻波与驻波比\|驻波与驻波比]]）。
- **位移幅值**：$\xi_0=u_0/\omega=1.59\times10^{-8}$ m——同例 1，声压量级与位移量级无直观对应。

## 例 4：级的合成与参考值陷阱

**题**：(a) 两个互不相干的声源各产生 $70$ dB，合成多少分贝？(b) 一个 $70$ dB、一个 $80$ dB，合成多少？(c) 同样记为 $90$ dB 的空气声与水声，各自的声压有效值是多少？(d) 水声 $150$ dB 与空气声 $90$ dB，哪个声强更大？

**解**：

1. **(a)** 功率型量按能量相加，$L=10\lg\left(10^{7.0}+10^{7.0}\right)=70+10\lg2=73.01$ dB。
2. **(b)** $L=10\lg\left(10^{7.0}+10^{8.0}\right)=10\lg(1.1\times10^{8})=80.41$ dB。**比大者只高 $0.41$ dB**——强源存在时弱源几乎不贡献。
3. **(c)** 由 $\mathrm{SPL}=20\lg(p_{\rm rms}/p_{\rm ref})$：
$$p_{\rm rms}=p_{\rm ref}\cdot10^{\mathrm{SPL}/20}=p_{\rm ref}\cdot10^{4.5}=3.162\times10^{4}\,p_{\rm ref},$$
$$\text{空气：}\ p_{\rm rms}=20\times10^{-6}\times3.162\times10^{4}=0.632\ \text{Pa};\qquad
\text{水：}\ p_{\rm rms}=1\times10^{-6}\times3.162\times10^{4}=0.0316\ \text{Pa}.$$
两者相差 $20$ 倍，正是 $20\lg20=26.0$ dB 的参考值差。
4. **(d)** 水声 $150$ dB：
$$p_{\rm rms}=1\times10^{-6}\times10^{7.5}=31.62\ \text{Pa},\qquad
I=\frac{p_{\rm rms}^2}{Z_c}=\frac{1000}{1.5\times10^6}=6.67\times10^{-4}\ \text{W/m}^2 .$$
空气声 $90$ dB：$I=0.632^2/414=9.66\times10^{-4}$ W/m²。
**空气中 90 dB 的声强反而更大。**

**检验**：

- **(d) 的分解**：水声 $150$ dB 与"同一声强的空气声级"之差应等于 $26.0$ dB（参考声压）$+35.6$ dB（阻抗）。推导：由 $I=p_w^2/Z_w$ 得 $p_w=\sqrt{IZ_w}$，同一 $I$ 在空气中给出 $p_a=\sqrt{IZ_a}=p_w/\sqrt{Z_w/Z_a}$，于是
$$\mathrm{SPL}_a=20\lg\frac{p_w}{20\ \mu\text{Pa}}-10\lg\frac{Z_w}{Z_a}
=20\lg\frac{31.62}{20\times10^{-6}}-35.6=123.98-35.6=88.4\ \text{dB}.$$
即水声 $150$ dB 等价于空气声 $88.4$ dB，而例中空气 $90$ dB 确实更大（对应 $I=9.66\times10^{-4}$ W/m² $>6.67\times10^{-4}$ W/m²）✓。比较声强**必须先换算**，不能比"级"。
- **级的合成不能用算术加法**：$70+70\ne140$（差 $67$ dB），$70+80\ne150$。
- **(a) 与 (b) 的一致性**：$70$ dB 与 $73.01$ dB 对应的能量比是 $1{:}2$；$70$ dB 与 $80$ dB 是 $1{:}10$，合成 $10\lg11=10.41$ dB 的增量，与 $73.01$ dB 的 $3.01$ dB 增量方向一致。
- **读数结论**：任何声级换回物理量之前，必须先确认三件事——参考值体系（空气 $20\ \mu$Pa / 水 $1\ \mu$Pa）、是峰值还是有效值、以及介质阻抗。
- 声强级与声压级之差在本库的两套参考体系下只差 $0.02$–$0.15$ dB（见例 1、例 2），可互相当作校核——**前提是场满足 $I=p_{\rm rms}^2/(\rho_0c)$**（单向平面行波、纯外行球面波）**且两侧用同一介质的参考体系**；驻波、混合场、界面干涉场里两个级之差随位置变化，不能这样互校。
