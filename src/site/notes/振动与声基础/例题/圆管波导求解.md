本篇演示 [[振动与声基础/概念/圆管波导与贝塞尔模态\|圆管波导与贝塞尔模态]] 的标准算法。套路：**查本征根 → 算截止频率 → 判传播 → 投影定幅值 → 写声压与振速 → 用壁面条件、源面还原、功率与频散关系校核**。除注明外参数统一取水：$c=1500$ m/s、$\rho=1000$ kg/m³、内半径 $a=0.05$ m，结果保留三到四位有效数字。例 1、例 2 是硬壁管，例 3、例 4 是软壁管。

换算常数先算一次，四例通用：

$$\frac{c}{2\pi a}=\frac{1500}{2\pi\times0.05}=4774.6\ \text{Hz},\qquad f_{cmn}=4774.6\,\chi_{mn}\ \text{(Hz)} .$$

$c_p$、$c_g$ 与功率的记号同 [[振动与声基础/概念/平行平面层波导与频散\|平行平面层波导与频散]]：$\beta=\sqrt{k^2-q^2}$，$c_p=\omega/\beta$，$c_g=c^2\beta/\omega$。

## 例 1：硬壁圆管的贝塞尔根与模式计数

**题**：水充满半径 $a=0.05$ m 的**绝对硬壁**圆管。求 $(0,0)$、$(1,1)$、$(2,1)$、$(0,1)$ 这四组 $(m,n)$ 的截止频率（按 $(m,n)$ 组计，不按简并后的空间模数计）；$f=5$ kHz 与 $f=10$ kHz 时可传播的独立空间模数；并给出任意激励下的几何单模频率范围。

**解**：

1. 硬壁本征根是 $J_m'$ 的正根，$q_{mn}=\chi^{\rm H}_{mn}/a$，$f_{cmn}=cq_{mn}/(2\pi)$：

| 模 $(m,n)$ | $\chi^{\rm H}_{mn}$ | $q_{mn}$ (1/m) | $f_{cmn}$ (kHz) |
|---|---|---|---|
| (0,0) | 0 | 0 | 0 |
| (1,1) | 1.84118378 | 36.82 | 8.79 |
| (2,1) | 3.05423693 | 61.08 | 14.58 |
| (0,1) | 3.83170597 | 76.63 | 18.30 |

$(0,0)$ 是 $q=0$ 的常数横模（$J_0(0)=1$），不是"$J_0'$ 的零点"推出来的通用零模。

2. 传播判据 $f>f_{cmn}$：

- $f=5$ kHz：只有 $(0,0)$，**1 个模**，横向均匀，就是自由场平面波；
- $f=10$ kHz：$(0,0)$ 与 $(1,1)$ 传播，$(2,1)$ 需 $14.58$ kHz、$(0,1)$ 需 $18.30$ kHz，都还没到。$(1,1)$ 有 $\cos\varphi$ 与 $\sin\varphi$ 两个**独立**角向分量（一般源对两者的复幅值不同），所以独立空间模是 $1+2=$ **3 个**，但不同的截止频率只有 $0$ 与 $8.79$ kHz **2 个**。

3. 几何单模：任意激励下只有 $(0,0)$ 传播，要求频率低于最低非平面模 $(1,1)$ 的截止频率：

$$0<f<\frac{c\,\chi^{\rm H}_{11}}{2\pi a}=\frac{1500\times1.84118378}{2\pi\times0.05}=8.79\ \text{kHz},$$
等价于 $a<\dfrac{1.84118378\,c}{2\pi f}$。

**检验**：

- **最低非平面根属 $m=1$，不是 $m=0$**：$1.8412$ 是 $J_1'$ 的首根；$3.8317$ 是 $J_0'$ 的首根（也等于 $J_1$ 的首根，见 $\chi^{\rm S}_{11}$）。把 $3.8317$ 当成"圆管最低截止"会把单模上限算大一倍多（$8.79\to18.30$ kHz）。
- **$q$ 与"同宽"平行板的对比**：取两板间距 $h=2a=0.10$ m 的双硬平行板，其第一阶横向波数是 $\pi/h=31.42$ rad/m，小于圆管的 $36.82$ rad/m，所以同"宽"下圆管的最低非平面截止更高（$8.79$ kHz vs $7.50$ kHz）。两者都随 $1/a$ 成反比，只是一个的量子化长度是 $\pi/h$、另一个是 $\chi/a$。
- **计数口径**：$10$ kHz 时若说"3 个模"，指的是 3 个独立空间模；若说"2 个截止值"，指 $f_c=0$ 与 $8.79$ kHz。$m\ge1$ 的二重简并使得这两个数不同，答题时要说明按哪种计。
- **轴对称激励是另一回事**：若源与 $\varphi$ 无关，$10$ kHz 时只有 $(0,0)$ 传播，第一个更高阶是 $(0,1)$（$18.30$ kHz）——这是"轴对称源单模"的上限，与上面的 $8.79$ kHz 不是一个数。
- 等号 $f=f_{c11}\approx8.79$ kHz 不算传播：上表的 $8.79$ kHz 是舍入值，只有 $f$ 恰等于该模截止频率时才有 $\beta_{11}=0$、$u_z\propto\beta$ 为零、幅值公式分母为零，不能代入。写"$f=8.79$ kHz"只在对量级时成立，判传播要回到严格的 $f>f_{c11}$。

## 例 2：硬壁圆管的均匀源与平面模功率

**题**：同上硬壁管（$a=0.05$ m、$c=1500$ m/s、$\rho=1000$ kg/m³），$f=5$ kHz，$z=0$ 处整个截面上给均匀轴向振速 $v(r,\varphi)=v_0=0.010$ m/s。求声压场、三分量振速与平均声功率，并校核壁面与源面条件。

**解**：

1. 截止与传播：$f=5$ kHz $<8.79$ kHz，只有 $(0,0)$ 传播；$k=\omega/c=2\pi\times5000/1500=20.94$ rad/m，$\beta_{00}=k$。
2. 投影：源是常数 $v_0$，与 $F_{00}=J_0(0)=1$ 同形，$v_{00}=v_0$。其余各阶全零，理由分两类：
   - $m\ge1$：$\int_0^{2\pi}\cos m\varphi\,\mathrm d\varphi=\int_0^{2\pi}\sin m\varphi\,\mathrm d\varphi=0$；
   - $m=0,n\ge1$：径向积分
$$\int_0^av_0J_0\!\left(\frac{\chi_{0n}r}{a}\right)r\,\mathrm dr=\frac{a^2v_0}{\chi_{0n}}J_1(\chi^{\rm H}_{0n})=0,$$
   因为 $J_1(\chi^{\rm H}_{0n})=-J_0'(\chi^{\rm H}_{0n})=0$（硬壁的定义）。
3. 幅值：$A_{00}=\dfrac{\rho\omega}{\beta_{00}}v_0=\rho cv_0=1000\times1500\times0.010=1.5\times10^4$ Pa。
4. 声压与振速：

$$p=1.5\times10^4e^{-j20.94z}\ \text{Pa},\qquad
u_z=0.010\,e^{-j20.94z}\ \text{m/s},\qquad u_r=u_\varphi=0,$$

以上是**相量**：时间因子 $e^{j\omega t}$ 不写进表达式（与全文一致），所以源面 $z=0$ 处核查时直接取 $e^{0}=1$。物理量取实部：$p_{\rm phys}=\operatorname{Re}\{pe^{j\omega t}\}=1.5\times10^4\cos(\omega t-20.94z)$ Pa，$u_{z,{\rm phys}}=0.010\cos(\omega t-20.94z)$ m/s。$p$ 与 $r,\varphi$ 无关，所以 $\partial p/\partial r=0$、$\partial p/\partial\varphi=0$。
5. 平均声功率：$\omega=3.1416\times10^4$ rad/s，$N_{00}=\pi a^2=7.854\times10^{-3}$ m²，

$$P=\frac12\rho cv_0^2\,\pi a^2=\frac12\times1000\times1500\times(0.010)^2\times7.854\times10^{-3}=0.589\ \text{W}.$$

**检验**：

- 壁面：$\partial p/\partial r\equiv0$ 时 $u_r(a)=0$ 自动成立；$\partial p/\partial\varphi=0$ 给出 $u_\varphi=0$，也自动满足。
- 源面还原：$z=0$ 处 $u_z=v_0$ 与题给一致，常数 $\sum v_\lambda F_\lambda=v_0$ 只有一项。
- 功率用通式复算：$P=\dfrac{\beta|A|^2N}{2\omega\rho}=\dfrac{20.94\times(1.5\times10^4)^2\times7.854\times10^{-3}}{2\times1000\times3.1416\times10^4}=0.589$ W，与 $\frac12\rho cv_0^2S$ 一致，因为 $(0,0)$ 的 $\beta=k$。
- 阻抗：$A_{00}/u_{z0}=\rho\omega/\beta=\rho c=1.50\times10^6$ Pa·s/m。**这是圆管里唯一等于介质特性阻抗的模态**；其他阶都是 $\rho c_p>\rho c$。
- 若源不均匀，结论会随源分布改变，而且**先按 $m$ 筛**：取平滑分布 $v\propto r\cos\varphi$（只含 $m=1$），角向积分把 $m=0$ 全部投掉——**包括 $(0,0)$**，因为 $\int_0^{2\pi}\cos\varphi\,\mathrm d\varphi=0$ 对常数本征函数同样成立。剩下的只有 $m=1$ 各阶，而 $f=5$ kHz 低于 $f_{c11}=8.79$ kHz，它们都是**倏逝模**（幅值仍由投影给出，$\beta_{11}=-j\alpha_{11}$），于是管内**没有传播模**，源面之外场随 $z$ 指数衰减，远处没有声场。一般非均匀源是否还带 $(0,0)$，只看它在常数 $1$ 上的投影 $\frac{1}{\pi a^2}\int_Sv\,\mathrm dS$ 是否为零。"均匀源只激平面模"是源分布与本征函数正交性的结果，不是"硬壁一定如此"：软壁的均匀源会激多个模（见 [[振动与声基础/例题/介质层与波导求解#例 8：双绝对软波导的均匀源投影与低于截止的衰减\|介质层与波导求解#例 8：双绝对软波导的均匀源投影与低于截止的衰减]] 的平行板对照）。

## 例 3：软壁圆管的截止与消逝模衰减

**题**：同尺寸圆管改为**绝对软壁**（$p(a)=0$），$a=0.05$ m、$c=1500$ m/s、$\rho=1000$ kg/m³。求前四组 $(m,n)$ 的截止频率（按组计；这四组确实是根值最小的四组，$m=3$ 的首根 $6.3802$ 已大于下表 $(0,2)$ 的 $5.5201$）；判断 $f=10$ kHz 时有无传播模；再对最低阶 $(0,1)$ 写出其衰减常数、$e$ 折距离与模态阻抗。

**解**：

1. 软壁本征根是 $J_m$ 的正根，$f_{cmn}=4774.6\,\chi^{\rm S}_{mn}$ Hz：

| 模 $(m,n)$ | $\chi^{\rm S}_{mn}$ | $q_{mn}$ (1/m) | $f_{cmn}$ (kHz) |
|---|---|---|---|
| (0,1) | 2.40482556 | 48.10 | 11.48 |
| (1,1) | 3.83170597 | 76.63 | 18.30 |
| (2,1) | 5.13562230 | 102.71 | 24.52 |
| (0,2) | 5.52007811 | 110.40 | 26.36 |

2. $f=10$ kHz $<f_{c01}=11.48$ kHz，**没有任何传播模**，整段管内只有源附近的倏逝场。
3. 最低阶 $(0,1)$ 的横向波数与衰减常数：$k=2\pi\times10^4/1500=41.89$ rad/m，$q_{01}=2.40482556/0.05=48.10$ rad/m，

$$\alpha_{01}=\sqrt{q_{01}^2-k^2}=\sqrt{48.10^2-41.89^2}=23.64\ \text{m}^{-1},\qquad
\frac{1}{\alpha_{01}}=0.0423\ \text{m}=42.3\ \text{mm}.$$

4. 轴向波数与模态阻抗：$\beta_{01}=-j\alpha_{01}=-j23.64$，声压的复振幅形式为 $p\propto J_0(2.40482556\,r/a)e^{-\alpha_{01}z}$（时间因子 $e^{j\omega t}$ 另计），

$$Z_{z,01}=\frac{\rho\omega}{\beta_{01}}=j\frac{\rho\omega}{\alpha_{01}}=j\frac{1000\times6.2832\times10^4}{23.64}=j\,2.66\times10^6\ \text{Pa·s/m}\quad(\text{纯虚}).$$

5. 平均轴向功率：单个倏逝模 $\operatorname{Re}\beta=0$，$I_z=0$，截面功率为零——只有无功的近场。

**检验**：

- 用 $f/f_{c}$ 复算：$\alpha=q\sqrt{1-(f/f_c)^2}=48.10\times\sqrt{1-(10/11.48)^2}=48.10\times0.4914=23.64$ m⁻¹。
- **软壁没有平面模**：所有 $\chi^{\rm S}_{mn}>0$，因此每阶都有正的截止频率；$10$ kHz 连最低阶都没到。对照例 1，同尺寸硬壁管在 $10$ kHz 已有 3 个独立空间模传播——软边界把最低截止从 $0$ 抬到 $11.48$ kHz。
- $\alpha$ 的符号与量级：$f\ll f_{c}$ 时 $\alpha\to q$（衰减变强、场更贴源面）；$f\to f_c^-$ 时 $\alpha\to0$（衰减长度发散，正好接上"截止点不衰减也不传播"）。本处 $f/f_c=0.871$，$\alpha/q=0.49$，处在中间。
- 纯虚阻抗说明不输运有功功率，与 [[振动与声基础/概念/全透射全内反射与消逝波\|全透射全内反射与消逝波]] 中消逝波法向阻抗为纯电抗是同一件事。**但不要把这个"零"推广**：含反向波或有限终端的组合、或多阶倏逝模的一般叠加，必须回到完整场解算 $I_z$。
- 等号 $f=f_{c01}\approx11.48$ kHz 要单独处理：$11.48$ kHz 是舍入值，只有 $f$ 恰等于 $f_{c01}$ 时 $\beta_{01}=0$，$A=\rho\omega v/\beta$ 分母为零，不能代入。

## 例 4：软壁圆管的单模激励与振速分布

**题**：同上软壁管（$a=0.05$ m、$c=1500$ m/s、$\rho=1000$ kg/m³），$f=15$ kHz。$z=0$ 处给轴向振速 $v(r)=v_0J_0\!\left(2.40482556\,r/a\right)$，$v_0=0.010$ m/s（与最低阶同形）。求传播模数、幅值、$\beta$、$c_p$、$c_g$、声压场、$u_z$ 与 $u_r$、壁面声压，以及平均声功率。

**解**：

1. 传播模数：$f=15$ kHz 满足 $f_{c01}=11.48<15<f_{c11}=18.30$ kHz，只有 $(0,1)$ 传播，**单模**。软壁没有 $(0,0)$，所以这个模已经是横向非均匀的。
2. 轴向波数：$k=2\pi\times15000/1500=62.83$ rad/m，$q_{01}=48.10$ rad/m，

$$\beta_{01}=\sqrt{k^2-q_{01}^2}=\sqrt{62.83^2-48.10^2}=40.43\ \text{rad/m}.$$
3. 幅值：源与 $F_{01}=J_0(2.40482556\,r/a)$ 同形，投影系数 $v_{01}=v_0=0.010$ m/s（正交性使其余阶为零）。$\omega=9.4248\times10^4$ rad/s，

$$A_{01}=\frac{\rho\omega}{\beta_{01}}v_0=\frac{1000\times9.4248\times10^4\times0.010}{40.43}=2.33\times10^4\ \text{Pa},$$
即 $A_{01}=\rho c_{p}v_0$。
4. 声压与振速（统一用**相量**：时间因子 $e^{j\omega t}$ 单列，轴向因子写成 $e^{-j40.43z}$；物理量取 $\operatorname{Re}\{(\cdot)e^{j\omega t}\}$）：

$$p=2.33\times10^4J_0\!\left(\frac{2.40482556\,r}{a}\right)e^{-j40.43z}\ \text{Pa},$$

$$u_z=\frac{\beta_{01}A_{01}}{\rho\omega}J_0\!\left(\frac{2.40482556\,r}{a}\right)e^{-j40.43z}
=0.010\,J_0\!\left(\frac{2.40482556\,r}{a}\right)e^{-j40.43z}\ \text{m/s},$$

$$u_r=j\frac{q_{01}A_{01}}{\rho\omega}J_0'\!\left(\frac{2.40482556\,r}{a}\right)e^{-j40.43z}
=-j\,0.0119\,J_1\!\left(\frac{2.40482556\,r}{a}\right)e^{-j40.43z}\ \text{m/s},$$

其中用了 $J_0'(z)=-J_1(z)$，$qA/(\rho\omega)=v_0q/\beta_{01}=0.010\times48.10/40.43=0.0119$ m/s；$u_\varphi=0$（$m=0$ 轴对称）。实量即 $p_{\rm phys}=\operatorname{Re}\{pe^{j\omega t}\}=2.33\times10^4J_0(2.40482556\,r/a)\cos(\omega t-40.43z)$ Pa。
5. 相速度、群速度：$c_{p}=\omega/\beta_{01}=2331$ m/s，$c_{g}=c^2/c_{p}=965$ m/s。
6. 壁面声压：$J_0(2.40482556)=0$ 是软壁本征根的定义，故 $p(a,z)=0$ 成立。
7. 平均声功率：平方范数 $N=\pi a^2J_1^2(\chi^{\rm S}_{01})=\pi\times0.05^2\times(0.51915)^2=2.117\times10^{-3}$ m²，

$$P=\frac{\beta_{01}|A_{01}|^2N}{2\rho\omega}
=\frac{40.43\times(2.33\times10^4)^2\times2.117\times10^{-3}}{2\times1000\times9.4248\times10^4}=0.247\ \text{W}.$$

**检验**：

- 源面还原：$z=0$ 处 $u_z=0.010\,J_0(2.40482556\,r/a)=v(r)$，与第 3 步的幅值互为校验。
- 硬壁与软壁的壁面条件对调着看：这里 $p(a)=0$ 是"给定"的，而 $u_r(a)=-j\,0.0119\times J_1(2.4048)=-j\,6.2\times10^{-3}$ m/s 不为零——软壁不约束法向振速，这是允许的（对照 [[振动与声基础/例题/介质层与波导求解#例 7：一侧硬壁一侧软壁的单模激励\|介质层与波导求解#例 7：一侧硬壁一侧软壁的单模激励]] 里边界的处理方式）。
- 阻抗：$A_{01}/u_{z0}=\rho c_p=2.33\times10^6$ Pa·s/m，**不是** $\rho c=1.50\times10^6$。这正是 $A_{01}=\rho c_pv_0$ 而非常见的 $\rho cv_0$ 的原因。
- 相位与波长：$\lambda_z=2\pi/\beta_{01}=0.155$ m $>\lambda=c/f=0.100$ m，波导内"沿轴看"的波长被拉长，与 $c_p>c$ 是同一件事。
- 频散关系：$c_pc_g=2331\times965=2.25\times10^6=c^2$。
- 功率两种算法一致：$\frac12\rho c_pv_0^2N=\frac12\times1000\times2331\times(0.010)^2\times2.117\times10^{-3}=0.247$ W。与例 2 的 $0.589$ W 不能直接比大小：两者的源分布不同（例 2 是均匀覆盖全截面，平方范数 $N=\pi a^2=7.85\times10^{-3}$ m²；本例的模在壁上为零、$N$ 只有 $2.12\times10^{-3}$ m²）。
- 近截止趋势：固定 $v_0$ 时 $A_{01}=\rho c_pv_0\propto1/\beta_{01}$，$f\to11.48$ kHz 时幅值发散、$c_g\to0$。这不是"可以无限提高功率"的许可，而是固定振速源在近截止处的阻抗失配；真实系统由源的内阻抗与壁面损耗限制，而本篇模型两者都没有。
