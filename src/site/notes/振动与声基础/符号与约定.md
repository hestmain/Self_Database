# 符号与约定

本页统一全课程的复数表示、物理量符号和方向约定。使用公式前先确认：采用哪一种时间因子、振幅是峰值还是有效值、速度沿哪个方向取正。

## 实量、复振幅和有效值

统一采用时间因子 $e^{j\omega t}$，$j^2=-1$：
$$
p(\mathbf r,t)=\operatorname{Re}\{\hat p(\mathbf r)e^{j\omega t}\},\qquad
\mathbf u(\mathbf r,t)=\operatorname{Re}\{\hat{\mathbf u}(\mathbf r)e^{j\omega t}\}.
$$
$\hat p$ 是复振幅，$|\hat p|$ 是峰值；对单频正弦量，$p_{\rm rms}=|\hat p|/\sqrt2$。**不能把峰值公式的 $1/2$ 与有效值公式混用**。$\omega=2\pi f$，$k=\omega/c=2\pi/\lambda$，周期 $T=1/f$。

正向平面波的空间因子为 $e^{-jkx}$；向外传播的球面波为 $e^{-jkr}/r$。这里的 $\hat p$ 仍含空间因子，不含时间因子。

## 机械振动

| 符号 | 含义 | SI 单位 |
|---|---|---|
| $x,v=\dot x,a=\ddot x$ | 位移、振速、加速度 | m、m/s、m/s² |
| $m$ | 质量 | kg |
| $D$ | 单自由度弹簧刚度 | N/m |
| $C_m=1/D$ | 力顺（柔度） | m/N |
| $R_m$ | 黏性阻力系数 | N·s/m |
| $\omega_0=\sqrt{D/m}$ | 无阻尼固有角频率 | rad/s |
| $\delta=R_m/(2m)$ | 衰减系数 | s⁻¹ |
| $\Omega=\sqrt{\omega_0^2-\delta^2}$ | 欠阻尼自由振动角频率 | rad/s |
| $Z_m=\hat F/\hat v$ | 机械阻抗，以速度为分母 | N·s/m |
| $X_{\rm react}=\omega m-D/\omega$ | 机械电抗，即 $Z_m$ 的虚部；不与位移峰值 $X_m$ 混淆 | N·s/m |

两个自由度系统：对地弹簧刚度记 $K_a,K_b$，耦合弹簧刚度记 $K_c$；等效刚度 $D_1=K_a+K_c$、$D_2=K_b+K_c$，$D_3=K_c$，$C_{m1}=1/K_a$、$C_{m2}=1/K_b$、$C_{m3}=1/K_c$。若有耦合参数 $k_1=K_c/D_1$、$k_2=K_c/D_2$，则 $\kappa=\sqrt{k_1k_2}$，用 $\kappa$ 避免与声波波数 $k$ 混淆。另记 $\mu=K_c/\sqrt{m_1m_2}$（s⁻²），用于能量传递式时须配合相应的质量比因子；它与球坐标分离变量中的 $\mu=\cos\theta$ 无关。

品质因数要看定义：按振幅衰减 $e^{-\pi}$ 所经历周期数定义，$Q_{\rm decay}=\Omega/(2\delta)$；按无阻尼固有频率定义的阻抗参数 $Q_0=\omega_0/(2\delta)$。弱阻尼时二者近似相等，不能在强阻尼下直接等同。见 [[振动与声基础/概念/阻尼自由振动与品质因数\|阻尼自由振动与品质因数]]。

## 声学场量与速度势

$p=P-P_0$ 为声压，$\rho'=\rho-\rho_0$ 为密度逾量，$s=\rho'/\rho_0$ 为相对压缩量。$\mathbf u$ 是介质质点振速，不是声速 $c$。压缩量 $s$ 不等于热力学熵，熵另记 $S$。

线性声学默认：均匀、静止、无黏、无热耗散流体，小振幅、等熵、无源区域。声速满足 $c^2=(\partial P/\partial\rho)_S$。$c_0$ 与 $c$ 均表示平衡态声速。

速度势采用负梯度定义：
$$
\mathbf u=-\nabla\Psi,\qquad p=\rho_0\frac{\partial\Psi}{\partial t},\qquad
\hat p=j\omega\rho_0\hat\Psi.
$$
有些资料取相反的势函数定义；不可只换其中一个符号。

$Z_c=\rho_0c$ 为介质特性阻抗，单位 Pa·s/m（瑞利）；波阻抗为场中具体的 $Z=\hat p/\hat u$，二者只有在相应单向平面行波中才直接相等。机械阻抗 $F/v$、比声阻抗 $p/u$ 不是同一个量。

## 界面法向、角度和系数

法向振速 $u_n$ 的正方向固定为**从介质 1 指向介质 2**。垂直入射用 $x$ 为正深度；斜入射用 $s$ 为正深度，切向坐标为 $y$。这里的深度坐标 $s$ 与前面的压缩量只在各自语境中使用。入射角、反射角、折射角均相对于法线（不是掠射角）。各篇会重申坐标。

- 声压反射系数 $R=\hat p_r/\hat p_i$；声压透射系数 $D_p=\hat p_t/\hat p_i$，不与弹簧刚度 $D$ 混淆。振幅均取各界面的参考面。
- 行波声强比 $R_I=I_r/I_i$、$T_I=I_t/I_i$；法向功率比 $R_W=W_r/W_i$、$T_W=W_t/W_i$。其中 $I_r$ 是反射波声强的正的大小。
- 传播型、无耗两流体界面：$R_W=|R|^2$，$T_W=T_I\cos\theta_t/\cos\theta_i$，$R_W+T_W=1$。斜入射一般不是 $R_I+T_I=1$。
- 法向行波阻抗统一写作 $Z_{jn}=\rho_j c_j/\cos\theta_j$，$j$ 是介质编号、$n$ 表示法向；层的输入阻抗另记 $Z_{\rm in}$，其中 $\rm in$ 是 input，不是介质编号加法向下标。

## 球函数与辐射方向

球坐标用 $(r,\theta,\varphi)$；阶数用 $\ell$、方位序数用 $m$。球汉克尔函数定义 $h_\ell^{(1)}=j_\ell+j n_\ell$、$h_\ell^{(2)}=j_\ell-j n_\ell$。在本库 $e^{j\omega t}$ 约定下，**$h_\ell^{(2)}$ 对应外行波，$h_\ell^{(1)}$ 对应内行波**。参见 [[振动与声基础/概念/球函数与球坐标分离变量\|球函数与球坐标分离变量]]。
